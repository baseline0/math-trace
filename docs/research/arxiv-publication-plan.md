### arXiv Metadata

**Category:** cs.GL (General Literature on Computer Science) or math.AT (Algebraic Topology)

**Keywords:** formula-code traceability, reproducibility, stochastic modeling, formal verification

**Abstract:**

> We present math-trace, a workflow for maintaining formula-code
> consistency in computational research. By treating symbolic
> formulas (SymPy) as the source of truth and automatically
> exporting to publication-quality typesetting (Typst), we
> reduce formula-code mismatches and improve reproducibility.
> We demonstrate the approach on a case study of stochastic
> P-system dynamics, where simulation validates theoretical
> predictions and formal proofs (Lean) verify key properties.
> The workflow is reproducible by construction: all code and
> formulas are version-controlled and can be regenerated from
> a single GitHub commit.

### GitHub Branch Strategy

When paper is ready to submit:

```bash
git checkout -b paper/v1
# Make any final tweaks (typos, formatting)
git commit -m "paper: arXiv v1 submission"
git tag -a arxiv/v1 -m "arXiv submission 2402.xxxxx"
git push origin paper/v1 paper/v1
git push origin arxiv/v1
```

This freezes the paper state. Readers can checkout exactly what was submitted:

```bash
git clone https://github.com/baseline0/math-trace.git
git checkout arxiv/v1
just paper  # Rebuild exact paper from arXiv
```

## arXiv Submission Process

1. Go to https://arxiv.org/submit
2. Upload PDF (generated from `just paper`)
3. Add source files (optional but recommended for reproducibility)
   - Include: model.py, simulate.py, build_paper.py, main.typ
   - Note: LaTeX/Typst source is unusual on arXiv, but acceptable
4. Fill metadata:
   - Title, authors, abstract (see above)
   - Categories: cs.GL or math.AT
   - Keywords: formula-code, reproducibility, etc.
5. Submit

**arXiv typically assigns identifier within 1 hour (e.g., 2402.12345)**
